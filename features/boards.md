# Boards

Boards are where tracked work becomes session-ready. Instead of copying an issue into chat, you can review work items in one table and start the team from the row that needs attention.

</figure>

## What It Shows

- Work item number and title.
- Source provider and details URL.
- Current status.
- Last relevant date.
- A run action for starting work from the item.

## Why It Helps

The board keeps incoming work close to the team. You can see what exists, choose the next item, and start the right session with less setup.

## Typical Flow

1. Open Boards from the app sidebar.
2. Scan work items by title, status, source, and date.
3. Open the details URL when you need the original issue.
4. Use the run action to start a team session for the selected item.
