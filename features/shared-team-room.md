# Shared Team Room

The shared team room is the main working space in TheTeam. It is where a request turns into a visible session with teammates, messages, notes, status, files, and actions.

</figure>

## What It Does

- Starts from a plain request instead of a formal workflow.
- Lets you choose which teammates should join.
- Shows the session title, current run controls, and workspace actions.
- Keeps the message stream and composer in the center.
- Shows teammate status and session notes beside the conversation.
- Tracks runtime and token information while the work is active.

## Why It Helps

You can watch the work happen without splitting context across separate chats. When someone joins later, the session already contains the conversation, notes, and handoff context they need.

## Typical Flow

1. Describe what you want to accomplish.
2. Choose the teammates who should help.
3. Start the session.
4. Let the team coordinate in the room.
5. Use notes and actions when the work needs a durable handoff or a next step.
