## More App Features

### Teammate Selection

The start screen lets you choose who joins the session. Lead, Neo, Oracle, Smith, Trinity, or any team you define can have different responsibilities, instructions, and tools.

### Session Notes

Notes are for the things that should not get lost in chat: plans, research, review findings, handoff packages, and decisions the team needs later in the same session.

### Session Actions

Session actions turn useful context into buttons. A session can expose actions such as running a command, opening a workspace, or launching a related URL when the needed variables are available.

### History

The sidebar separates active, unfinished, and completed sessions, so paused work and past results are easy to find again.

### Statistics

Statistics show tokens, cost, sessions, average session time, messages per session, agent activity, and trends over time.

### Memory

Memory lets the team keep useful project facts and preferences across sessions, so common decisions do not need to be rediscovered every time.
